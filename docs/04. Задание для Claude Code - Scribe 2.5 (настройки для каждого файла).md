# Задание для Claude Code - Scribe 2.5: настройки для каждого файла

## 1. Настройки для каждого файла

Сейчас параметры справа общие: два файла в очереди (английский и русский) обрабатываются с одними и теми же настройками.

Андрей предложил: выбрал файл, задал ему настройки - он идёт в обработку. Дизайн-чат предлагает так, чтобы не потерять «добавил пачку - нажал одну кнопку»:

1. **У каждого файла свои настройки** (язык, формат, говорящие, таймкоды, итоги).
2. **Новый файл получает текущие настройки** - последние выбранные, как сейчас. Пачку одинаковых файлов по-прежнему обрабатывает одна кнопка.
3. **Щелчок по карточке выделяет файл**, панель справа показывает **его** настройки, и изменения применяются только к нему. Заголовок панели: «Настройки: lesson.m4a».
   - Выделение нескольких (Cmd/Shift-щелчок) - изменение применяется ко всем выделенным.
   - Ничего не выделено - панель задаёт настройки для **новых** файлов: «Настройки для новых файлов».
4. **На карточке - короткая строка настроек этого файла:** «Авто · Word · говорящие · итоги». Сразу видно, что у английского и русского файлов разные параметры.
5. Во время обработки настройки файла в работе не меняются, остальных - можно.
6. «Расшифровать» обрабатывает все файлы в очереди, каждый со своими настройками.

Не делать: обязательное ручное подтверждение настроек для каждого файла. С «Авто» язык и так определяется сам, а лишний шаг замедлит пачку.

Проверка через окно, обе темы, снимки:
- два файла с разными языком и форматом → два правильных результата;
- выделение нескольких;
- смена настроек у файла в очереди во время обработки другого.

## 2. Решение Андрея: процессор, смешанные записи

На процессоре смешанная запись занимает до 2,5 ч на час записи. **Разрешено:** на процессоре (Windows/Linux без NVIDIA) определять язык фраз маленькой моделью whisper-base без перепроверки большой.

Условие - замер на тестовом наборе:
- доля фраз с верным языком не хуже чем на 2 п. п. от полного способа;
- урок и вставка находятся.

Если хуже - оставить как есть и написать. На Mac и NVIDIA ничего не меняется.
