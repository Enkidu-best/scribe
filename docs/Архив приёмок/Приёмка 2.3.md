# Приёмка Scribe 2.3 - «Авто» и смешанные записи

Задание: `docs/02. Задание для Claude Code - Scribe 2.3 (Авто и смешанные записи).md`. Дата: 14.10.2026.

**Коротко.**
- **Что изменилось.** «Авто» теперь перед распознаванием проверяет язык фраз по всей записи.
  Если звучат и русский, и английский, запись сама уходит в «Несколько», и в карточке пишется
  «Найдены русский и английский - обработано как смешанная запись».
- **Запись Андрея.** «New Recording 9.m4a» в «Авто» через окно теперь даёт 3058 букв русского
  текста (без меток «Спикер N») вместо нуля. Русские места на 17:22, 20:05 и 54:05 есть.
- **Ложные срабатывания.** На наборе их ноль, на реальной чисто русской записи (54 мин) - тоже.
- **Время.** «Авто» на чистых коротких записях не изменилось (±0,3 с).
- **Ручной выбор.** При «Русский» / «English» режим не меняется, но если в записи заметно
  другого языка - в карточке предупреждение.

---

## 1. Как устроена проверка (общее решение, без правил под запись)

`multilang.probe_languages`, вызывается из `whisper_gui.transcribe_auto`:

1. **Фразы** - Silero VAD (тот же, что в 2.2), берутся фразы от 1,5 с. Для языка достаточно 10 с
   из середины фразы.
2. **Сито** - маленькая модель **whisper-base**. Она даёт вероятности ru и en для **всех** фраз,
   ~25 мс на фразу, в 15–20 раз дешевле turbo. Выборка не нужна, поэтому удача выборки ни на
   что не влияет.
3. **Основной язык** - у сита, если оно уверенно слышит один язык на ≥ 80 % речи. Иначе -
   turbo по 6 фразам, равномерно по записи. Причина: английский с русским акцентом сито
   принимает за *украинский*.
4. **Отметки и перепроверка.**
   - Сильные отметки (у сита p второго языка ≥ 0,3) turbo проверяет порциями по 8, от самых
     подозрительных; порция без единой фразы второго языка - стоп.
   - Слабые отметки (сито не уверено даже в основном языке) - сначала выборка из 8, дальше
     порциями, пока находится второй язык.
5. **Решение.** Запись смешанная, если turbo уверенно (≥ 0,9) подтвердил **хотя бы 2 фразы**
   второго языка и они занимают **≥ 2 % времени речи**. Одна случайная фраза не считается.

**Если смешанная** - обработка как «Несколько» (движок 2.2), в строке этапов добавляется шаг:
«Шаг 1 из 3 · …: проверка языков» → «Шаг 2 из 4 · Разбивка на фразы и определение языка».

**Если нет** - обычный путь, но с основным языком, найденным проверкой по всей записи. Раньше
Whisper в «Авто» решал язык по первым 30 секундам.

**Если язык выбран вручную** - режим не меняется. Если в записи есть заметно другого языка (по
тому же правилу) - предупреждение в карточке.

Если whisper-base недоступна (нет в кэше и нет сети), проверка идёт запасным путём - выборкой
фраз через turbo; это медленнее. Модель весит ~145 МБ и скачивается при первом «Авто».

### Почему так, а не иначе (по замерам)

- **Выборка 30–40 фраз (как в задании) ненадёжна на записи Андрея.** Уверенно русских фраз в ней
  всего 11 из 289 уверенных (3,8 %). При выборке 40 фраз «смешанная» определялась в 97 % вариантов
  выборки, при 60 и пороге 5 % - только в 57 % (порог по доле «съедает» 2–3 попадания).
- **Порог по доле фраз хрупок, порог по доле *времени* устойчив.** Русские реплики длинные
  (11–22 с), а случайная ошибка в чистой записи - одна короткая фраза.
- **Проверка по 30-секундным окнам прямо во время распознавания (было бы бесплатно) не годится.**
  На уроке и записи со вставкой ни одно окно не показало второй язык - в смешанном окне побеждает
  основной. А на чистой русской записи 4 окна оказались «английскими».
- **Только turbo (без сита)** стоил 10–21 с на короткий файл - это нарушило бы требование
  по времени.

## 5. Попутно

- **Редкое падение при выходе процесса.** Изредка процесс падал после всей работы - при разборе
  C++-объектов Metal/onnxruntime («recursive_mutex lock failed», 2 раза примерно из 20 запусков
  скриптов). Чтобы macOS не показывала «Python неожиданно завершился» при закрытии Scribe,
  после закрытия окна процесс выходит через `os._exit(0)` (настройки к этому моменту
  сохранены, диктофон остановлен).
- Сито грузится своей копией и не вытесняет turbo из общего кэша моделей.

## 6. Ограничения

- **Короткие вставки второго языка (< 2 % речи или одна фраза)** «Авто» не считает смешанной
  записью - это осознанный порог против ложных срабатываний. Для таких записей есть ручной
  «Несколько».
- **Смесь внутри одной фразы без паузы** (как на 54:05) по-прежнему слабое место. Здесь
  сработало, но в 2.2 на 26:13 русские слова внутри длинной английской фразы терялись.
- **Время проверки на часовых записях** ~20-25 с без нагрузки (до ~45 с, когда видеокарту
  делит другая задача).

## 7. Как повторить

```
python3 tests/make_test_audio.py english english_accent   # новые записи набора
python3 tests/measure_auto.py                               # решения на наборе
python3 tests/measure_auto.py --file "~/Downloads/New Recording 9.m4a"
python3 tests/measure_auto.py --file "<чистая запись>" --expect pure
python3 tests/measure_auto.py --timing quiet english dictation english_accent -- mix
```
