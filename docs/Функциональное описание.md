## 1. Коротко

Scribe - настольная программа для Mac на Apple Silicon (код работает и на Windows / Linux), которая переводит аудио- и видеозаписи в текст **полностью на этом компьютере**. Распознавание - Whisper large-v3-turbo: на Mac через Apple MLX, на Windows / Linux через faster-whisper (видеокарта NVIDIA или процессор). Результат - файл Word, текст или субтитры рядом с исходной записью; по желанию - метки говорящих (pyannote) и отдельный документ «итоги» (локальная языковая модель через Ollama). Второй раздел - **Диктофон**: живая диктовка с микрофона, текст появляется по мере речи.

Для кого: владелец - записи встреч, лекций, уроков (в том числе смешанные русский / английский), диктовка заметок. Главные сценарии (`Продукт.md` нет - по README):
- UC-01 расшифровать одну запись (перетащить → «Расшифровать: …» → файл рядом с записью открывается сам);
- UC-02 расшифровать несколько файлов, у каждого свои настройки;
- UC-03 смешанная запись RU / EN («Авто» сам замечает второй язык или режим «Несколько»);
- UC-04 говорящие («Спикер 1, 2…»);
- UC-05 итоги из новой или готовой расшифровки;
- UC-06 диктовка с микрофона и сохранение в .txt / .docx;
- UC-07 расшифровка без окна (`scribe_cli.py`).

Версия - **2.7**: `core.py:87` (`APP_VERSION`), её показывает низ меню. ⚠ разрыв: номер записан вручную в четырёх местах - `core.py:87`, `setup.py:34-35`, `packaging/scribe.iss:4`, `.github/workflows/release.yml:57`; стандарт 1.1 - версия «из пакета», из одного места.

### 3.2 «Расшифровка»

- **Назначение:** превратить записи в текстовые файлы (UC-01…UC-05).
- **Как попасть / как уйти:** пункт меню «Расшифровка» (открыт при запуске) или перетаскивание файлов в окно; уход - другой пункт, список и выделение остаются. Новый запуск программы - пустой список (стандарт 3.4 выполнен).

- **Назначение:** скачать нужные модели один раз или взять их из офлайн-пакета (без интернета).

### 3.8 Командная строка `scribe_cli.py` (без окна)

- **Назначение:** расшифровка без окна (сервер, Windows `scribe-cli.exe`, проверки) - UC-07.
- **Вызов:** `scribe_cli.py [--lang auto|ru|en|multi] [--fmt txt|docx|srt] [--out папка] [--json отчёт.json] [--model turbo|large-v3|medium|small|base] [--no-normalize] файлы…`; `--engine` - выбранный движок и пути (настройки, журналы, модели) в JSON; `--download-models` - скачать нужные модели.
- **Поведение:** по умолчанию «Авто», .txt рядом с записью; ход - строки «<файл>: 25 %…», итог «готово: <файл> → <результат> · N с на M с звука». Берёт замок видеокарты как **фоновый** прогон («Scribe (командная строка)»), ждёт молча («жду видеокарту: «X», с …» раз в минуту) и между файлами уступает человеку. Код выхода 1 - если хоть один файл с ошибкой.
- Ссылки: `scribe_cli.py:35-151`.

  ⚠ разрыв: в командной строке нет защиты от совпадения имён («a.mp4» и «a.m4a» → один «a.txt», второй перезапишет первый), которая есть в окне (`scribe_cli.py:65`, ср. `whisper_gui.py:1367-1375`).

- **Ограничения:** без говорящих, таймкодов и итогов; модель - из `--model`, а не из Настроек окна (папка моделей - из Настроек).

### 3.9 Процесс распознавания диктофона (для других программ)

- **Назначение:** отдельный процесс, который держит модель и распознаёт фразы диктофона; его же запускает Legal Knowledge Desk (голосовой ввод) из соседней папки.

Связь - локальный сокет (Windows - именованный канал) с ключом. В собранной программе запускается как `Scribe --dictaphone-worker`.
- Ссылки: `dictaphone_worker.py:15-78`, `whisper_gui.py:37-48`, `dictaphone.py:383-409`.
- **Ограничения:** замка видеокарты процесс не берёт - его берёт тот, кто запустил (диктофон Scribe; Legal Knowledge Desk - см. его описание). Стандарт 7.1 предлагает заменить связь между проектами общим модулем `common/stt/`.

**Продолжение расшифровки** (06 Б): готовые куски файла - в папке данных программы «Продолжение расшифровки» (`core.RESUME_DIR`, для проверок - `SCRIBE_RESUME_DIR`), по папке на файл и настройки (путь, размер, время изменения файла, модель, язык, нормализация). Готовый результат сохранён - папка убирается; прерванные и забытые - через 30 дней при запуске программы.

**Выбор движка:** Apple Silicon - MLX; иначе faster-whisper на NVIDIA (float16) или процессоре (int8); при ошибке CUDA - сам на процессор. Переопределение для проверок: `SCRIBE_ENGINE=mlx|fw`, `SCRIBE_DEVICE=cpu|cuda`, `SCRIBE_LID=lite|full` (`engine.py:613-651`, `multilang.py:91-100`).

**Форматы:** вход - аудио `.m4a .mp3 .wav .aac .flac .ogg .oga .opus .aiff .aif .wma .m4b .amr .mka .ape .wv .caf .ac3`, видео `.mp4 .mov .m4v .mkv .webm .wmv .avi .flv .3gp .3g2 .ts .mts .m2ts .mpg .mpeg .asf .vob .ogv` (`core.py:63-70`), готовые расшифровки `.txt .docx .srt`; результат - `.docx`, `.txt`, `.srt`, итоги `.docx` / `.txt`; диктовка - `.txt` / `.docx`.

## 6. Чего нет и почему

- **Глоссария терминов нет** - решение владельца (HANDOFF, п. 6): редкие термины - предел модели; задание 06 Б тоже «без ручного словаря».
- **Живого текста при расшифровке файла нет** - он есть в «Диктофоне» (HANDOFF, п. 6).
- **Правки расшифровки в окне нет** - результат открывается в Word / редакторе.
- **Списка прошлых расшифровок нет** - новый запуск начинается с пустого списка; готовую расшифровку можно перетащить обратно для итогов.
- **«Справки», RU | EN, «Aa» нет** - проект остановлен до перевода на стандарт (вопрос 1).
- **Выбора «чем считать» нет** - движок выбирается сам по железу; «На процессоре» - только как ответ на занятую видеокарту или нехватку памяти.
- **Говорящих, таймкодов и итогов в командной строке нет** - только распознавание.
- **Корзины нет** - Scribe не удаляет файлы на диске.
- **Облачного распознавания и облачных моделей нет** - всё на этом компьютере; сеть нужна только для скачивания моделей, проверки токена и ссылок.
- **Готовые движки вместо Whisper** (GigaAM-v3, onnx-asr и др.) - отложено: `docs/Задание на будущее - готовые движки (НЕ НАЧИНАТЬ).md`.
