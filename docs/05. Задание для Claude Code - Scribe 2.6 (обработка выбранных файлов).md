# Задание для Claude Code - Scribe 2.6: обработка только выбранных файлов

## Что не так (Андрей, 15.10)

Андрей добавил два файла, выбрал один, задал ему настройки и нажал «Расшифровать». Ожидал, что обработается только выбранный файл, а второй спокойно подождёт своей очереди. Программа обработала оба.

Причина в 2.5: «Расшифровать» берёт всю очередь, а новые файлы ещё и выделяются автоматически.

## Сделать

1. **Главная кнопка работает с выделенными файлами.** Текст кнопки говорит, что будет сделано:
   - выделен один файл - «Расшифровать: lesson.m4a» (длинное имя сокращать);
   - выделено несколько - «Расшифровать выбранные (3)»;
   - ничего не выделено - кнопка неактивна, подсказка «Выберите файл в списке».
2. **Рядом вторая, спокойная кнопка «Все файлы (N)».** Перед запуском - вопрос: «Расшифровать все N файлов в очереди? У каждого будут его настройки.» Варианты «Расшифровать все» и «Отмена». N - файлы со статусом «Ждёт», готовые не считаются.
3. **Новые файлы не выделяются автоматически,** кроме случая, когда список был пуст и добавлен ровно один файл: тогда он выделен, и сразу можно нажать «Расшифровать».
4. Невыбранные файлы остаются со статусом «Ждёт», их настройки не меняются.
5. Во время работы можно выделить другой файл и поставить его в очередь кнопкой «Добавить в очередь»: обработается после текущего.
6. Горячая клавиша Cmd/Ctrl+A - выделить все.

## Проверка через окно (обе темы, снимки)

- Два файла, выбран один → обработан только он, второй «Ждёт».
- «Все файлы» → вопрос → оба, каждый со своими настройками.
- Выделены 2 из 3 → обработаны 2.
- Во время работы добавить в очередь третий.
- Один файл в пустой список → выделен сам.
