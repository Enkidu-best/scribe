# Задание на будущее: Scribe - готовые движки вместо своего (НЕ НАЧИНАТЬ)

Версия 18.10.2026. **Разработка Scribe остановлена.** Это задание - чтобы не потерять выводы. Начинать только по прямой команде Андрея.

Основа - `docs/Готовые решения и подходы (обзор 18.10).md`.

## Что сделать, когда вернёмся (по пользе к усилиям)

1. **Silero VAD перед распознаванием** (если ещё нет). У Whisper:
   - `condition_on_previous_text=False`;
   - жёстче `compression_ratio_threshold` и `no_speech_threshold`.
2. **pyannote community-1** вместо 3.1: pyannote.audio 4.x, режим `exclusive_speaker_diarization`.
3. **GigaAM-v3 e2e через onnx-asr** - основной движок для русского:
   - пунктуация встроена, текст в тишине не выдумывает;
   - Mac (CoreML), Windows (DirectML/CUDA), Linux.

   Whisper остаётся для английского и записей, где английского много.
4. **Английские термины латиницей без глоссария.** Проход локальной LLM по тексту блоками: «верни латиницей англоязычные термины, записанные транслитом; смысл не меняй». Контекст - название записи или приложенный документ.
5. **Сравнение на реальных записях Андрея**: GigaAM-v3, Parakeet-v3, Whisper turbo. Мерить ошибки, галлюцинации, скорость. Таблица в отчёт, выбор - за Андреем.
6. **Установщик Windows** - по образцу aTrain и Buzz. Код noScribe не брать (GPL).
