# Задание для Claude Code - Scribe 2.3: режим «Авто» и смешанные записи

## Что случилось

Андрей расшифровал «New Recording 9.m4a» (59 мин, урок английского с русскими репликами) в 2.2 и получил текст **без единого русского слова**: кириллица только в метках «Спикер N».

Разбор дизайн-чата:
- Текст совпадает с выводом английских блоков 2.1, а не с прогоном «Несколько» 2.2 из `tests/results/2.2-file.json` (сверено по началу текста; цитаты из записи убраны перед публикацией).
- В прогоне 2.2 «Несколько» по тому же файлу русского текста есть: 85 сегментов, 3 038 букв кириллицы против 2 546 в 2.1.
- Значит, запись шла в режиме **«Авто»** (или «English»). Модель один раз решила «английский» на весь файл, и русские реплики выпали или были переведены. Сам движок «Несколько» исправен. Слабое место - «Авто» молча выдаёт плохой результат на смешанной записи.

Пользователь не обязан помнить про режим. Нужно общее решение.

## Сделать

1. **«Авто» сам замечает второй язык.**
- После разбивки на фразы (Silero VAD уже есть) определить язык у выборки фраз по всей длине записи: например, 30-40 фраз, равномерно, короче 1,5 с не брать.
- Если заметная доля фраз - другой язык (порог подобрать на тестовом наборе, ориентир 5-10 %, при уверенности ≥ 0,9), запись автоматически обрабатывается как «Несколько».
- В карточке файла - пометка «Найдены русский и английский - обработано как смешанная запись».
- Если второго языка нет - обычный «Авто», скорость прежняя.
- Цена проверки - секунды, замерить.

2. **«Русский» / «English» выбраны вручную, а в записи много другого языка** (та же выборка) - предупреждение в карточке после обработки: «В записи есть английская речь - для смешанной записи выберите «Авто» или «Несколько»». Режим не менять: пользователь выбрал сам.

3. **Подсказки режимов** переписать понятнее:
- «Авто - язык определится сам; если в записи два языка, это тоже будет учтено»;
- «Несколько» оставить для явного выбора.

4. **Проверка:**
- тестовый набор `tests/` (урок, длинная вставка, чисто русская и чисто английская записи) в режиме «Авто»: смешанные уходят в «Несколько», чистые - нет, ложных срабатываний 0;
- «New Recording 9.m4a» (Андрей положит её в `~/Downloads`, если там нет) в режиме «Авто» через окно: русские места на 17:22, 20:05, 54:05 есть в тексте;
- время «Авто» на чистой записи не выросло больше чем на несколько секунд.

5. Отчёт - дописать раздел в `docs/Приёмка 2.2.md` или новый `docs/Приёмка 2.3.md`. Коммит, версия 2.3.
