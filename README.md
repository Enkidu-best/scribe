# Scribe — локальная транскрипция аудио и видео в текст

Настольное приложение для Mac (Apple Silicon). Переводит аудио- и видеозаписи
в текст **полностью локально** — без интернета, подписок и отправки данных
куда-либо. Ядро распознавания — Whisper через фреймворк Apple **MLX** (быстрый
на M-чипах).

---

## Что умеет

- Перетаскивание файлов в окно или выбор кнопкой; пакетная обработка нескольких файлов.
- Вход — аудио и видео: `m4a, mp3, wav, aac, flac, ogg, opus, aiff, mp4, mov, m4v, mkv, webm` (и всё, что читает ffmpeg).
- Языки: авто, русский, английский.
- **Режим «Несколько языков»** — для записей, где русский и английский идут блоками (например, урок на английском + разговор на русском). Приложение само находит границы языков и распознаёт каждый блок на своём языке, без «сползания» в один язык.
- Форматы результата: **Текст (.txt)**, **Word (.docx)**, **Субтитры (.srt)**.
- Разбивка текста на абзацы; опциональные таймкоды.
- Определение говорящих (Спикер 1, Спикер 2 …) через pyannote.
- Нормализация громкости (снижает ошибки на неровном звуке).
- Настоящий прогресс-бар и таймер.

Результат сохраняется рядом с исходным файлом, автоматически.

---

## Как это работает (кратко)

- Обычная запись на одном языке: один быстрый проход распознавания.
- Режим «Несколько языков»: запись декодируется один раз в память, язык
  определяется по записи разреженно (редкие «якоря» + уточнение границ), соседние
  куски одного языка склеиваются в крупные блоки, каждый блок распознаётся одним
  вызовом с явно заданным языком. Это даёт и скорость, и чистые границы.

Модель распознавания скачивается автоматически с Hugging Face при первом запуске
и кэшируется — в репозитории её нет.

## Установка

Нужен Mac на Apple Silicon. Команды выполняются в приложении «Терминал».

### 1. Homebrew и ffmpeg

Если Homebrew ещё нет:
```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```
Затем ffmpeg (нужен для чтения аудио/видео):
```
brew install ffmpeg
```

### 2. Python и зависимости

Используется **Python с python.org** (в нём есть Tkinter), а не из Homebrew.
Проверьте свою версию пути:
```
/Library/Frameworks/Python.framework/Versions/3.14/bin/python3 -m pip install -r requirements.txt
```

Проверка, что ядро на месте:
```
/Library/Frameworks/Python.framework/Versions/3.14/bin/python3 -c "import tkinter, mlx_whisper, customtkinter; print('OK')"
```

## Запуск

### Через терминал
```
/Library/Frameworks/Python.framework/Versions/3.14/bin/python3 "/путь/к/whisper_gui.py"
```

### Иконкой (без терминала) — через Automator
1. Откройте **Automator** → Новый документ → **Программа**.
2. Добавьте действие **«Запустить shell-скрипт»**.
3. Впишите (подставьте свой путь к скрипту):
```
/Library/Frameworks/Python.framework/Versions/3.14/bin/python3 "/путь/к/whisper_gui.py"
```
4. Сохраните как «Scribe». Двойной клик по иконке запускает окно.

## Определение говорящих (диаризация)

Нужен бесплатный токен Hugging Face — разовая настройка.

1. Зарегистрируйтесь на **huggingface.co**.
2. Примите условия модели: **huggingface.co/pyannote/speaker-diarization-community-1** (войдите в аккаунт и нажмите Agree / Accept).
3. Создайте токен: **huggingface.co/settings/tokens** → New token → тип **Read**.
4. В приложении: **⚙︎ Настройки** → вставьте токен → **Проверить**.

Диаризация заметно медленнее транскрипции — добавляет минуты к часовому файлу.

## Ограничения

- **Термины внутри фразы.** Если внутри русской фразы есть отдельные английские
  слова (RACI, deadline), они распознаются на языке блока (русском). Разделение
  по языкам работает на уровне блоков, а не отдельных слов.
- **Галлюцинации на тишине/шуме.** На тишине и неразборчивой речи Whisper может
  выдумывать текст. В приложении включены меры против этого; помогает нормализация
  громкости.

---

## Диагностика

- `command not found: mlx_whisper` — запускайте полным путём к python.org-Python.
- `No module named '_tkinter'` — запущен Homebrew-Python вместо python.org.
- `No such file or directory: 'ffmpeg'` — `brew install ffmpeg`.
- Говорящие не проставляются — проверьте токен в Настройках и приём условий модели.
