# Scribe - локальная транскрипция аудио и видео в текст

Настольное приложение для **Mac (Apple Silicon)**, **Windows** и **Linux**. Переводит аудио-
и видеозаписи в текст **полностью локально** - без подписок и отправки данных куда-либо.
Ядро распознавания - Whisper. Движок Scribe выбирает сам, по железу:

| Компьютер | Движок | Строка в Настройках |
|---|---|---|
| Mac на Apple Silicon | Apple **MLX** | «Распознавание: Apple MLX (видеоядро)» |
| Windows / Linux с видеокартой NVIDIA | **faster-whisper** (CUDA, float16) | «Распознавание: NVIDIA (видеокарта)» |
| Остальные | **faster-whisper** (int8) | «Распознавание: процессор - медленнее» |

На процессоре Scribe честно предупреждает, что будет медленнее: в карточке файла - оценка
времени по замерам на этом же компьютере, у галочки «Определять говорящих» - что это
ещё в несколько раз дольше. Диктофон на процессоре, если текст отстаёт от речи больше
чем на 5 с, сам переходит на модель Small (на 4 ядрах: turbo - 9-12 с на фразу, Small - 2-4 с)
и пишет об этом; модель можно выбрать и вручную в Настройках.

## Что умеет

Одно окно с боковым меню - **Расшифровка**, **Диктофон**, **Настройки**, переключатель
темы (системная / светлая / тёмная). Оформление - как у Legal Knowledge Desk.

- Перетаскивание файлов (или целой папки) в окно, либо выбор кнопкой; пакетная обработка.
- У каждого файла в списке свой статус (в очереди / идёт / готово / ошибка) и кнопки
  «Открыть», «Итоги», «Показать в Finder». Расшифровку можно **остановить**.
- Под шкалой прогресса - этап прямым текстом: «Файл 2 из 5 · Шаг 3 из 5 ·
  Распознавание речи - 43 %».
- **Итоги** (галочка «Итоги (отдельный файл)», по умолчанию выключена) - отдельный документ
  `<имя> - итоги.docx/.txt` рядом с полной расшифровкой: суть, главное, решения,
  задачи (кто - что - срок), открытые вопросы. Готовит локальная модель через
  **Ollama** (по умолчанию `qwen3.5:9b`) - текст никуда не уходит. Полная расшифровка
  остаётся как есть. Если Ollama не запущена - Scribe запустит её сам.
- Забыли галочку - у готового файла есть кнопка **«Подвести итоги»**: итоги из готовой
  расшифровки, без повторного распознавания. Можно перетащить в окно и старую
  расшифровку (.docx / .txt / .srt) - у неё будет та же кнопка.
- `a.mp4` и `a.m4a` из одной папки не перезаписывают друг друга: «a (m4a).txt».
- **У каждого файла свои настройки** (язык, формат, говорящие, таймкоды, итоги) - короткой строкой
  на карточке: «Авто · Word · говорящие · итоги». Щелчок по файлу - панель справа показывает и меняет
  только его настройки («Настройки: lesson.m4a»); Cmd-щелчок (на Windows и Linux - Ctrl) добавляет
  файл к выделению, Shift-щелчок - диапазон. Только что добавленные файлы выделены сразу: поменяли
  язык - это для них. Ничего не выделено (Esc или щелчок по пустому месту) - панель задаёт настройки
  для новых файлов. «Расшифровать» обрабатывает всю очередь, каждый файл - со своими настройками;
  у файлов, которые ждут очереди, настройки можно менять и во время обработки.
- Новый файл получает последние выбранные настройки; они запоминаются между запусками.
- Вход - аудио и видео: MP3, WAV, M4A, AAC, FLAC, OGG, MP4, MOV, MKV, WEBM, WMV, AVI и многие другие - всё, что читает ffmpeg (полный список - в **⚙︎ Настройках**).
- Языки: **Авто** (по умолчанию), русский, английский, несколько.
- **«Авто» сам замечает второй язык**: перед распознаванием быстро проверяет язык фраз по
  всей записи; если в ней звучат и русский, и английский - обрабатывает её как «Несколько»
  и пишет об этом в карточке файла. Чистая запись идёт обычным путём (проверка - 0,1-2 с на
  коротком файле, ~20-30 с на часовом). Проверка языков идёт только в «Авто»:
  если язык выбран вручную («Русский», «English»), её нет - вся запись сразу распознаётся на этом
  языке (с 2.5).
- **Режим «Несколько»** - для записей, где русский и английский чередуются, хоть каждые
  несколько секунд (урок английского, разговор с вставками). Язык определяется для
  каждой фразы, поэтому короткие куски на другом языке не теряются и не переводятся.
- Форматы результата: **Word (.docx)** (по умолчанию), **Текст (.txt)**, **Субтитры (.srt)**.
- Разбивка текста на абзацы; опциональные таймкоды.
- Определение говорящих (Спикер 1, Спикер 2 …) через pyannote.
- Нормализация громкости (снижает ошибки на неровном звуке; включена, выключается в Настройках).
- Настоящий прогресс-бар и таймер.
- **Диктофон** (раздел в меню) - живая диктовка с микрофона: текст появляется по мере речи, с кнопками Пауза/Стоп, авто-определением языка, пунктуацией и сохранением в .txt или .docx. Фразы режет детектор речи Silero VAD: фраза закрывается паузой от 0,5 с, длинная речь без пауз режется в самой тихой точке (не позже 25 с). Распознавание идёт в отдельном процессе; если он упадёт - перезапустится сам, фраза не потеряется. Отключили наушники - диктофон переключится на системный микрофон; микрофон можно выбрать в окне.

Результат сохраняется рядом с исходным файлом, автоматически.

## Как это работает (кратко)

- Обычная запись на одном языке: один быстрый проход распознавания.
- «Авто»: детектор речи режет запись на фразы; маленькая модель **whisper-base** («сито»,
  ~25 мс на фразу) смотрит язык всех фраз и отмечает подозрительные; основная модель
  перепроверяет только их. Подтверждены хотя бы 2 фразы второго языка на ≥ 2 % времени
  речи - запись смешанная. whisper-base (~145 МБ) скачивается при первом запуске «Авто»;
  без неё проверка идёт медленнее, выборкой основной модели.
- Режим «Несколько»: запись декодируется один раз в память; детектор речи Silero VAD
  режет её на фразы по паузам; язык каждой фразы определяет сама модель Whisper;
  неуверенные короткие фразы распознаются и как ru, и как en - побеждает более
  правдоподобный для Whisper вариант (без зацикливаний); соседние фразы одного языка
  склеиваются в блоки до ~30 с. Фразы, которые Whisper пропустил внутри блока,
  распознаются ещё раз. Подробности и замеры - `multilang.py`, `docs/Приёмка 2.2.md`.

Модель распознавания скачивается автоматически с Hugging Face при первом запуске
и кэшируется - в репозитории её нет.

## Windows: установщик

1. Скачайте **Scribe-Setup-2.4.exe** со страницы релизов:
   https://github.com/Enkidu-best/scribe/releases (≈ размер - в описании релиза).
2. Запустите. Установщик не подписан сертификатом, поэтому Windows SmartScreen может
   показать «Windows защитила ваш компьютер» - нажмите **Подробнее → Выполнить в любом
   случае**. Права администратора не нужны: программа ставится для текущего пользователя.
   Ярлык - в меню «Пуск» (и на рабочем столе, если отметить). Удаление - «Параметры →
   Приложения» или ярлык «Удалить Scribe».
3. При первом запуске откроется окно **«Загрузка моделей»**: список моделей с размерами
   (распознавание Whisper turbo ≈ 1,6 ГБ, проверка языка whisper-base ≈ 140 МБ,
   определение говорящих pyannote ≈ 35 МБ - по желанию) и кнопка «Скачать». Детектор
   речи Silero уже внутри программы.

**Без интернета.** Скачайте с той же страницы релизов **офлайн-пакет моделей**
`Scribe-models-2.4.zip`, перенесите на компьютер, распакуйте и выберите папку в
**Настройки → «Загрузить модели из папки…»**. В пакете - Whisper turbo, whisper-base и
pyannote (лицензии и авторство - в `NOTICE.txt` внутри).

**ffmpeg** уже внутри программы - сборка LGPL от BtbN (https://github.com/BtbN/FFmpeg-Builds),
лицензия GNU LGPL 2.1+; исходный код ffmpeg - https://ffmpeg.org. Лицензия - в папке
программы `_internal\ffmpeg\LICENSE.txt` (или `ffmpeg\LICENSE.txt`).

**Видеокарта NVIDIA.** Установщик один. Если в компьютере есть NVIDIA с драйвером, в
Настройках появится кнопка **«Ускорение на видеокарте NVIDIA»**: она скачивает
официальные библиотеки NVIDIA cuBLAS и cuDNN (≈ 1,2 ГБ) в папку данных Scribe, после
перезапуска распознавание идёт на видеокарте. Нужен драйвер NVIDIA версии 525 или новее.

**Итоги.** Ollama в установщик не входит (это отдельная программа на несколько ГБ).
Кнопка «Итоги» без Ollama объяснит, как её поставить: https://ollama.com/download,
затем `ollama pull qwen3.5:9b`.

## Windows и Linux из исходников

Нужен **Python 3.10-3.12** и **ffmpeg** в PATH.

- Windows: Python с python.org (галочка «Add to PATH»), ffmpeg - `winget install Gyan.FFmpeg`.
- Linux (Ubuntu/Debian): `sudo apt install python3-venv python3-tk ffmpeg libportaudio2`.

```
python -m venv .venv
.venv/bin/pip install -r requirements.txt          # Windows: .venv\Scripts\pip ...
.venv/bin/python whisper_gui.py                    # окно
```

Только командная строка (сервер, без окна и без pyannote): `pip install -r requirements-cli.txt`.

**NVIDIA на Linux / из исходников:** нужен драйвер NVIDIA, CUDA 12 и cuDNN 9. Проще всего
`pip install nvidia-cublas-cu12 nvidia-cudnn-cu12` и
`export LD_LIBRARY_PATH=$(python -c 'import nvidia.cublas.lib, nvidia.cudnn.lib, os; print(os.path.dirname(nvidia.cublas.lib.__file__) + ":" + os.path.dirname(nvidia.cudnn.lib.__file__))')`.
Проверка: `python scribe_cli.py --engine` должна показать `"device": "cuda"`.
Принудительно: `SCRIBE_DEVICE=cpu` / `SCRIBE_ENGINE=fw`.

Где хранится: настройки - `%LOCALAPPDATA%\Scribe\settings.json` (Windows),
`~/.config/Scribe/settings.json` (Linux); журнал диктофона - `%LOCALAPPDATA%\Scribe\Logs`,
`~/.local/state/Scribe/log`. На Mac - как раньше (`~/.audio2text.json`, `~/Library/Logs/Scribe`).

## Командная строка

```
python scribe_cli.py запись.m4a                     # «Авто», .txt рядом с записью
python scribe_cli.py --lang multi --fmt docx a.mp3  # «Несколько», Word
python scribe_cli.py --engine                       # какой движок выбран
python scribe_cli.py --download-models              # скачать модели заранее
```
В установленной программе для Windows - `scribe-cli.exe` в папке программы.

## Скорость

Минут работы на час записи (модель turbo; замеры октября 2026, подробно - `docs/Приёмка 2.4.md`):

| Компьютер | Одноязычная запись | Смешанная ru/en («Несколько») | Диктофон, фраза ~4 с |
|---|---|---|---|
| Mac M4, Apple MLX | 3-4 мин | 6-13 мин | 0,9 с |
| Linux в Docker на Mac M4, 4 ядра процессора | 13 мин | 15-40 мин (до 2.5 - 53-100) | - |
| GitHub Actions Linux, 4 ядра x86 | 38 мин | - | turbo 8,9 с · small 2,0 с |
| GitHub Actions Windows, 4 ядра x86 | 43-49 мин | - | turbo 11,7 с · small 3,6 с |

На процессоре язык фраз определяет только маленькая модель whisper-base, без перепроверки
большой (с 2.5): CTranslate2 считает каждую короткую фразу полным окном 30 с, и перепроверка turbo
делала смешанную запись в 2-2,5 раза длиннее самой записи. На тестовом наборе точность та же
(`docs/Приёмка 2.5.md`). На Mac и NVIDIA - полный способ, как раньше. Видеокарту NVIDIA проверить
не на чем - цифр для неё нет.

## Установка на Mac

Нужен Mac на Apple Silicon. Команды выполняются в приложении «Терминал».

### 1. Homebrew, ffmpeg и PortAudio

Если Homebrew ещё нет:
```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```
Затем ffmpeg (чтение аудио/видео) и portaudio (микрофон для диктофона):
```
brew install ffmpeg portaudio
```

### 2. Python и зависимости

Используется **Python с python.org** (в нём есть Tkinter), а не из Homebrew.
Рекомендуется **Python 3.12** - на нём собирается приложение (см. ниже; py2app
пока не работает с 3.14). Установка зависимостей и упаковщика:
```
/Library/Frameworks/Python.framework/Versions/3.12/bin/python3 -m pip install -r requirements.txt py2app
```

Проверка, что ядро на месте:
```
/Library/Frameworks/Python.framework/Versions/3.12/bin/python3 -c "import tkinter, mlx_whisper, customtkinter, sounddevice; print('OK')"
```

## Сборка приложения (.app)

Чтобы получить настоящее приложение с запуском по двойному клику (и корректным
доступом к микрофону для диктофона), собираем его упаковщиком **py2app**.

Важно: py2app пока не работает с Python 3.14, поэтому сборку делаем на **Python 3.12**
(его можно поставить с python.org рядом с 3.14, не заменяя его).

Соберите приложение (alias-режим - лёгкий, без копирования пакетов внутрь):
```
cd "/путь/к/проекту"
/Library/Frameworks/Python.framework/Versions/3.12/bin/python3 setup.py py2app -A
```
Готовое приложение появится в `dist/Scribe.app`. Двойной клик; при первом запуске
macOS спросит доступ к микрофону - разрешите. Если предупредит про «неопознанного
разработчика» - правый клик по иконке → «Открыть».

Alias-режим ссылается на исходники, поэтому правки в коде подхватываются **без
пересборки** - достаточно перезапустить приложение.

## Определение говорящих (диаризация)

Нужен бесплатный токен Hugging Face - разовая настройка.

1. Зарегистрируйтесь на **huggingface.co**.
2. Примите условия модели: **huggingface.co/pyannote/speaker-diarization-community-1** (войдите в аккаунт и нажмите Agree / Accept).
3. Создайте токен: **huggingface.co/settings/tokens** → New token → тип **Read**.
4. В приложении: **⚙︎ Настройки** → вставьте токен → **Проверить**.

Без токена галочка «Определять говорящих» неактивна - если только модель уже не взята
из офлайн-пакета («Загрузить модели из папки…»): тогда токен не нужен. Диаризация заметно медленнее
транскрипции - добавляет минуты к часовому файлу.

## Итоги (Ollama)

1. Установите Ollama с **ollama.com** (или `brew install ollama`).
2. Скачайте модель: `ollama pull qwen3.5:9b` (≈6,6 ГБ; на 8 ГБ памяти - `qwen3.5:4b`).
3. В окне отметьте «Итоги». Модель можно сменить в **Настройках**.

Короткая запись пересказывается одним запросом; длинная - сначала по частям, затем
итог. На M4 это ~30 с на получасовую запись и пара минут на часовую.

## Ограничения

- **Термины внутри фразы.** Если внутри русской фразы есть отдельные английские
  слова (RACI, deadline), они распознаются на языке блока (русском). Разделение
  по языкам работает на уровне блоков, а не отдельных слов.
- **Галлюцинации на тишине/шуме.** На тишине и неразборчивой речи Whisper может
  выдумывать текст. В приложении включены меры против этого; помогает нормализация
  громкости.

## Диагностика

- `command not found: mlx_whisper` - запускайте полным путём к python.org-Python.
- `No module named '_tkinter'` - запущен Homebrew-Python вместо python.org.
- `No such file or directory: 'ffmpeg'` - `brew install ffmpeg`.
- Сборка `.app` падает на Python 3.14 - собирайте на 3.12 (py2app пока не поддерживает 3.14).
- Диктофон не пишет / не появляется текст - смотрите `~/Library/Logs/Scribe/dictaphone.log`.
- Итоги не сделаны - причина написана под файлом в списке; проверьте Ollama в Настройках.
- Говорящие не проставляются - проверьте токен в Настройках и приём условий модели.

## Файлы проекта

- `whisper_gui.py` - приложение (окно); `core.py` - расшифровка без окна (декодирование,
  «Авто», «Несколько», диаризация, запись результатов); `scribe_cli.py` - командная строка.
- `engine.py` - движок распознавания: MLX на Mac, faster-whisper (CUDA или процессор) иначе.
- `platform_util.py` - всё, что зависит от системы: пути, открытие файлов, канал диктофона.
- `models.py` - какие модели нужны, скачивание, офлайн-пакет, библиотеки NVIDIA.
- `packaging/` - сборка для Windows (PyInstaller + Inno Setup); `.github/workflows/` - проверки
  на Windows и Linux и сборка установщика; `tools/make_offline_pack.py` - офлайн-пакет моделей.
- `theme.py` - оформление: цвета и элементы в стиле Legal Knowledge Desk.
- `summary.py` - итоги через Ollama.
- `multilang.py` - режим «Несколько»: язык для каждой фразы.
- `vad.py` - детектор речи Silero VAD (модель `assets/models/silero_vad.onnx`, MIT).
- `tests/` - сборка тестового набора (`make_test_audio.py`), замеры режима «Несколько»
  (`measure_multilang.py`, `compare_langid.py`), нормализации (`measure_normalize.py`),
  автотесты нарезки (`test_vad.py`). Аудио набора в git не кладётся.
- `dictaphone.py` - страница диктофона (захват микрофона, нарезка на фразы).
- `dictaphone_worker.py` - процесс распознавания для диктофона.
- `setup.py` - сборка `.app` через py2app.
- `requirements.txt` - зависимости (для Mac, Windows и Linux); `requirements-cli.txt` - без окна.
- `scribe.png`, `scribe.icns` - иконка; `assets/icons/` - иконки интерфейса (Lucide, ISC).
