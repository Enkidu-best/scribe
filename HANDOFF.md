# Scribe - передача контекста (handoff)

Документ для продолжения работы в новом чате / Claude Code: что это, как устроено,
что уже сделано, известные ограничения и что не трогать.

Текущая версия: **2.7** (октябрь 2026: пункты А, Б, В, Г задания 06 готовы, «Приёмка 2.7» - `docs/Приёмка 2.7.md`). История: 1.1 → 2.0 (MLX, диаризация) →
2.1 (одно окно в стиле Legal Knowledge Desk, итоги через Ollama) → 2.2 (язык для
каждой фразы, Silero VAD, надёжный диктофон, доводка окна) → 2.3 («Авто» сам замечает
второй язык и уходит в «Несколько») → 2.4 (Windows и Linux: слой движка, установщик .exe,
офлайн-пакет моделей, командная строка) → 2.5 (настройки для каждого файла; на процессоре язык
фраз определяет только whisper-base) → 2.6 (обрабатываются только выделенные файлы, «Все файлы» -
с вопросом, очередь во время работы).

---

## 1. Что это

Настольное приложение для Mac (Apple Silicon), Windows и Linux: аудио и видео в текст
**полностью локально**. Распознавание - Whisper large-v3-turbo: на Mac через Apple MLX,
на Windows/Linux через faster-whisper (CUDA на NVIDIA, иначе процессор, int8). Интерфейс -
customtkinter, оформление как у Legal Knowledge Desk (LKD). Автор - Андрей,
MacBook Pro M4, 16 ГБ. Ценит скорость и минимум настроек в окне.

## 2. Файлы

- `whisper_gui.py` - окно (меню: Расшифровка, Диктофон, Настройки, Тема), окно
  «Загрузка моделей», оценка времени по замерам этой машины.
- `core.py` - всё без окна: декодирование, «Авто», «Несколько», диаризация, запись .txt/.docx/.srt.
  Его используют окно, `scribe_cli.py` (командная строка, `scribe-cli.exe`) и замеры.
- `engine.py` - движок: `MLXEngine` (на Mac - ровно прежние вызовы mlx_whisper) и `FWEngine`
  (faster-whisper; CUDA float16 или CPU int8, при ошибке CUDA - сам уходит на процессор);
  выбор - `get_engine()`, переопределение `SCRIBE_ENGINE=mlx|fw`, `SCRIBE_DEVICE=cpu|cuda`.
  Детектор языка фраз (`lid()`) - у каждого движка свой, интерфейс один.
- `platform_util.py` - пути (Mac - прежние; Windows/Linux - platformdirs), открыть/показать
  файл, адрес канала диктофона (AF_UNIX / AF_PIPE), ffmpeg из сборки, DLL CUDA.
- `models.py` - какие модели нужны, скачивание с прогрессом, «Загрузить модели из папки…»,
  библиотеки NVIDIA (cuBLAS/cuDNN с PyPI) для Windows.
- `packaging/` (PyInstaller + Inno Setup), `.github/workflows/` (ci.yml - проверки на
  Windows и Linux; release.yml - установщик, тихая установка, проверка, удаление, релиз),
  `tools/make_offline_pack.py` - офлайн-пакет моделей.
- `multilang.py` - режим «Несколько» (RU/EN): язык для каждой фразы; проверка языков для «Авто».
- `vad.py` - Silero VAD (ONNX, `assets/models/silero_vad.onnx`, MIT): фразы для режима
  «Несколько» и для диктофона.
- `dictaphone.py` - страница «Диктофон» (захват, нарезка, связь с воркером).
- `dictaphone_worker.py` - процесс распознавания для диктофона. **Его же запускает LKD**
  (голосовой ввод, `kb_desk/asr.py`). Протокол не менять (см. п. 5).
- `summary.py` - итоги через Ollama (`<имя> - итоги.docx/.txt`).
- `theme.py` - цвета и элементы LKD; иконки Lucide в `assets/icons` (PNG-маски).
- `tests/` - сборка тестового набора, замеры, автотесты (аудио набора в git нет).
- `docs/` - задания и приёмка (`Приёмка 2.2.md` со снимками и таблицей замеров).
- Настройки: Mac `~/.audio2text.json`, Windows `%LOCALAPPDATA%\Scribe\settings.json`,
  Linux `~/.config/Scribe/settings.json`. Лог диктофона: `~/Library/Logs/Scribe/dictaphone.log`
  (Windows - `%LOCALAPPDATA%\Scribe\Logs`). `scribe_cli.py --engine` печатает все пути.

Запуск для разработки: `/Library/Frameworks/Python.framework/Versions/3.12/bin/python3 whisper_gui.py`.
Сборка .app: py2app в alias-режиме (README).

## 3. Как устроено

**Файлы.** Один проход ffmpeg в память (16 кГц моно, `loudnorm` в том же проходе;
сбой фильтра - предупреждение в карточке и обработка как есть). Этапы: подготовка звука →
(фразы и языки) → распознавание → (говорящие) → сохранение → (итоги). Строка под шкалой:
«Файл 2 из 5 · Шаг 3 из 5 · Распознавание речи - 43 %».

**Режим «Авто» (2.3).** `whisper_gui.transcribe_auto` → `multilang.probe_languages`:
фразы (Silero VAD, ≥ 1,5 с, середина до 10 с); сито whisper-base (своя копия модели, не
вытесняет turbo из ModelHolder) даёт p(ru), p(en) всех фраз. Основной язык - у сита, если
оно уверенно слышит один язык на ≥ 80 % речи, иначе turbo по 6 фразам (английский с русским
акцентом сито считает украинским). Сильные отметки (p второго ≥ 0,3) и выборка слабых
(сито не уверено в основном) перепроверяются turbo порциями по 8 с остановом, когда порция
пуста. Смешанная: ≥ 2 подтверждённых фраз второго языка на ≥ 2 % времени речи → «Несколько»
и пометка в карточке. Иначе - один язык, найденный проверкой (а не по первым 30 с, как решал
бы сам Whisper). При ручном «Русский»/«English» проверки языков нет (2.5): сразу распознавание на выбранном языке. Без whisper-base -
запасной путь: выборка turbo. После закрытия окна процесс выходит через `os._exit(0)`
(редкое падение onnxruntime/Metal при разборе объектов).

**Режим «Несколько» (2.2).** Silero VAD режет запись на фразы по паузам от 0,3 с
(длиннее 25 с - в самой тихой точке). Язык фразы - детектор самой модели Whisper, пакетом,
вход дополнен до 10 с (до 5 с - ошибается; 30 с - в 3,5 раза медленнее при тех же
решениях). Неуверенные (<0,9) и короткие (<1,5 с) фразы, если язык соседей не
подтверждает, распознаются и как ru, и как en; выигрывает лучший avg_logprob среди
незацикленных (compression_ratio ≤ 2,4), а если оба варианта одним алфавитом - этот язык.
Соседние фразы одного языка - блоки до 28 с. Подсказка блока - последнее предложение
прошлого блока того же языка **и только того же алфавита** (иначе Whisper переводит).
Зациклившийся блок - повтор с температурой 0,2-0,6. Фразы, которые Whisper пропустил
внутри блока, распознаются ещё раз. Выбор детектора - по замеру
(`tests/compare_langid.py`): SpeechBrain VoxLingua107 на реальной записи хуже (английский
с акцентом принимал за русский).

**Итоги.** Ollama (`qwen3.5:9b` по умолчанию), JSON по схеме, оформление своё. Перед
вызовом выгружаются Whisper и pyannote (`free_asr_models`), последний запрос с
`keep_alive=0`. «Подвести итоги» - из сегментов в памяти или из сохранённого .txt/.docx/.srt.

**Диктофон.** Кадры 32 мс → `vad.StreamSegmenter` (фраза закрывается паузой 0,5 с;
длинная речь - разрез в самой тихой точке последних 3 с, предел 25 с) → один поток-диспетчер
говорит с воркером: фраза → ответ → следующая. Воркер упал/завис - перезапуск, неотвеченная
фраза уходит заново (больше 3 перезапусков за минуту - стоп с сообщением). Нет кадров 1,5 с -
переподключение к выбранному или системному микрофону. Подсказка - последнее законченное
предложение до 100 знаков. Одинаковая фраза подряд не вставляется. Список «галлюцинаций»
срабатывает, только если речи по детектору было меньше 0,4 с.

**Настройки для каждого файла (2.5).** `Job.opts` - язык, формат, говорящие, таймкоды, итоги.
Новый файл получает `App.defaults` (последние выбранные, хранятся в настройках) и сразу выделяется.
`App.sel` - выделенные файлы; панель справа показывает настройки первого из них (`_panel_load`), изменение
(`_opt_changed`) идёт всем выделенным, кроме файла в работе (`job.locked`), и становится «последним
выбранным». Обработчик читает настройки файла в момент, когда берёт его в работу (`_job_opts`), -
поэтому у файлов в очереди их можно менять во время обработки других. Готовый файл после изменения
настроек снова встаёт в очередь.

**Выбранные файлы и очередь (2.6).** Состояния файла: «Ждёт» (`queue`, в списке, не запущен) →
«В очереди» (`sched`, поставлен на обработку) → идёт (`run`) → готово / ошибка / остановлено. Главная
кнопка (`start`) ставит в очередь выделенные файлы, «Все файлы (N)» (`start_all`) - все «Ждёт» после
`_confirm`. Обработчик (`_worker`) один, берёт файлы из `run_queue` по одному, пока очередь не пуста;
во время работы `start` дописывает очередь («Добавить в очередь»). «Остановить» возвращает не начатые
файлы в «Ждёт». Новые файлы не выделяются, кроме единственного файла в пустом списке.

**Процессор (2.5).** `multilang.lite()`: на CPU (или `SCRIBE_LID=lite|full`) язык фраз в «Авто» и
«Несколько» определяет только сито whisper-base (`LITE_SURE` = 0,7), без перепроверки turbo.

**Одна нить MLX (2.7, А).** Все вызовы MLX - прогрев, распознавание, детектор языка, выгрузка - идут через
`engine.MLXExecutor`: одна долгоживущая нить, остальные ставят задачу и ждут. Причина: потоки вычислений MLX
привязаны к нити; после сбоя (нехватка памяти) недовычисленные массивы в кэшах mlx_whisper (`mel_filters`,
`hanning`, `_positional_embedding` модели) роняли следующий запуск в новой нити: «There is no Stream(gpu, N)
in current thread». После любой ошибки распознавания - `_reset()` (модель, кэш MLX, кэши mlx_whisper); модель,
загруженная не исполнителем, выгружается перед задачей (`_guarded`). Проверка - `tests/test_mlx_thread.py`
(`--old` воспроизводит ошибку старым способом).

**Проценты и ошибки (2.7, В).** Подготовка звука - процент по полученным от ffmpeg секундам звука против
длительности (звук копится в одном `bytearray`: на 3 ч ~690 МБ вместо ~2 ГБ в пике); проверка языков - свой
процент; у этапа - «осталось ~N мин» по его скорости (`App._eta`). Ошибки - `core.explain_error` (по-русски,
с действием), полный текст - `log_error` в журнал `scribe-errors.log`. Нехватка памяти видеокарты - окно
«Подождать очереди / На процессоре / Отмена» (`App._ask_oom`); «На процессоре» - этот файл через
`engine.cpu_engine()` (faster-whisper, в первый раз скачивает модель ≈ 1,6 ГБ) внутри `engine.using(...)`, сито
«Авто» у каждого движка своё.

**Длинные файлы (2.7, Б).** Файл одного языка («Авто» без второго языка, «Русский», «English») - режим «файл»
общего модуля `common/stt/` (эталон - «Разработка ПО/_общие модули/stt», копию не править, обновлять
`sync_common.sh stt "Аудио в Текст"`): фразы Silero VAD → куски до 30 с строго по паузам → пачки по 8
(`engine.LONG_BATCH`; MLX - один вызов кодера и декодера на пачку в нити MLX, faster-whisper -
`BatchedInferencePipeline`). Кусок, упёршийся в предел токенов, дописывается следующей пачкой; зациклившийся -
обычным вызовом с запасными температурами. Готовые куски сразу на диск (`core.RESUME_DIR` = данные программы /
«Продолжение расшифровки», в проверках `SCRIBE_RESUME_DIR`): после сбоя или «Остановить» у файла «Продолжить
(готово N %)»; после результата папка убирается, забытые - через 30 дней. Проверка до внедрения (A/B, лекция
2 ч 57 мин и собрание 54 мин) - `tests/ab_long.py`, `tests/ab_speakers.py`; сбой и продолжение вживую -
`tests/live_resume_06b.py`. «Несколько» и смешанная запись - по фразам (`multilang.py`), как раньше.

**Очередь видеокарты (23.10, «_Общие модули 01»).** Общий замок `.heavy-lock` - копия общего модуля
`common/lock/` (эталон и описание - «Разработка ПО/_общие модули/lock/README.md»; копию не править, обновлять
`_общие модули/scripts/sync_common.sh lock "Аудио в Текст"`). Под замком: проход очереди файлов (берётся перед
первым файлом, отдаётся после последнего), «Подвести итоги», запись диктофона (на «Паузе» дольше 15 мин -
отпускает сам), `scribe_cli.py` (фон, уступает человеку между файлами). Занято - окно «Видеокарта занята: «…»,
с 16:31, …» с «Подождать очереди» / «Запустить сейчас» / «Отмена» (у диктофона ещё «На процессоре» - модель
Small через faster-whisper, если она на диске; на M4 фраза 4 с - 1,0 с). Пока ждём - у файлов «Ждёт видеокарту»,
кнопка «Отменить ожидание»; шапка «Расшифровки» - «Модель: готова / работает / занята «…» [- в очереди] /
работает вместе с «…» / нет модели». Не запущенный файл - «Не начат» (Scribe 06 Г); один добавленный файл
выделяется сам; нет выделения - подсказка «Щёлкните файл в списке или нажмите «Все файлы»». Переменные:
`HEAVY_LOCK` (путь, в проверках - временная папка), `SCRIBE_HEAVY_LOCK_HELD=1` (замок держит запустивший),
`HEAVY_LOCK_WHO=background|human`.

## 5. Не трогать без крайней нужды

- **Протокол `dictaphone_worker.py`** (его запускает LKD): воркер → `("ready")`, `("warmed")`,
  `("text", str)`, `("error", str)`; основной → `(audio_float32, lang, prompt)` или `None`.
- **Обходы pyannote:** аудио в диаризацию - как waveform (обход сломанного torchcodec);
  токен через `huggingface_hub.login()`; разбор `DiarizeOutput.speaker_diarization`.
- Против галлюцинаций в обычном режиме: temperature=0, condition_on_previous_text=False.

## 6. Известные ограничения

- **Смесь внутри одной фразы без паузы** («повторим слово apple», русские слова посреди
  английской фразы): блок распознаётся основным языком. Если слово сказано тем же голосом,
  Whisper обычно оставляет его латиницей (8/8 на тесте); вклеенное чужим голосом выбрасывает.
  Специальных правил нет (решение задания 2.2).
- Время «Несколько» на записях с частой сменой языка - до ~18 мин на час.
- Редкие термины (RACI → «раси») - предел модели. **Глоссарий не делаем** (решение Андрея).
- Живой текст при расшифровке файла не делаем - он есть в «Диктофоне».
